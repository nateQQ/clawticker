# Mascot sprites

`claudepix-frames.json` is the ClaudePix pixel-animation library by @amaanbuilds
(https://claudepix.vercel.app/): 13 presets, 20x20 grid, 216 frames. The JSON is
the resolved frame data as published by https://github.com/igouss/claudepix-rs
(`gen/frames.json`).

**Licence status:** ClaudePix states no licence. The artwork is included here
for credit and interoperability with no claim of ownership and without a
redistribution grant from its author. If you are the author and want it
removed or licensed, open an issue and it will be replaced. To swap in other
sprites, keep the same JSON shape and run `python3 tools/gen_sprites.py`.
