# Changelog

## 1.0.0 - 2026-11-18

First public release.

- Daemon: Claude usage (5h and 7d windows), Codex usage, CoinGecko prices, finished-turn detection, HTTP `/payload`, per-board display mode override.
- Firmware for the DIYMORE ES3C28P: Claude or AI usage screen with pace markers, Coin table, animated Splash, Finished screen, Settings (brightness, display mode), captive-portal setup with custom logo upload.
- `install.sh` (macOS launchd, Linux systemd) with `--no-start` and `--uninstall`, `flash.sh`.
